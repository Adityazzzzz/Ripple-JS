# `watch()`

While `effect()` automatically tracks all signals read synchronously during its execution, sometimes you only want to react when a *specific* piece of state changes. `watch()` provides a precise, Vue-style watcher that runs a callback only when its explicit source changes.

## Usage

`watch(source, callback, options?)` takes a source function (or a signal), a callback function, and optional configuration.

```ts
import { signal, watch } from 'ripple-reactive';

const count = signal(0);
const name = signal('Alice');

// Only runs when `count` changes, even if `name` is accessed inside the callback.
watch(
  () => count(),
  (newCount, oldCount) => {
    console.log(`Count changed from ${oldCount} to ${newCount}`);
    // Reading name here does NOT make the watcher depend on name
    console.log(`Current name is ${name()}`);
  }
);

count(1); // Logs: Count changed from 0 to 1, Current name is Alice
name('Bob'); // Does NOT trigger the watcher
```

<Callout type="info">
The callback inside `watch()` is automatically wrapped in `untrack()`. This means any signals you read inside the callback will not be tracked as dependencies for the watcher.
</Callout>

## Immediate Execution

By default, `watch()` is lazy: the callback does not run immediately upon creation; it only runs on the next change. To make it run immediately, use `{ immediate: true }`.

```ts
import { signal, watch } from 'ripple-reactive';

const isOnline = signal(true);

watch(
  () => isOnline(),
  (online) => {
    console.log(`User is now ${online ? 'online' : 'offline'}`);
  },
  { immediate: true }
); 
// Logs immediately: "User is now online"
```

## `watch()` vs `effect()`

| Feature | `effect()` | `watch()` |
|---------|-----------|-----------|
| **Dependencies** | Implicit (auto-tracked) | Explicit (via source function) |
| **Execution** | Immediate | Lazy by default |
| **Callback tracking** | Tracks all signals read | Callback is untracked |
| **Use case** | UI rendering, derived synchronization | Side-effects on specific state changes |

## Real-world Example: API Calls on State Change

A common use case for `watch()` is debouncing API calls based on a search query.

```ts
import { signal, watch } from 'ripple-reactive';

const searchInput = signal('');
const results = signal([]);

watch(
  () => searchInput(),
  async (query) => {
    if (query.length < 3) {
      results([]);
      return;
    }
    
    const res = await fetch(`/api/search?q=${encodeURIComponent(query)}`);
    const data = await res.json();
    results(data);
  }
);
```

## Signatures

```ts
interface WatchOptions {
  immediate?: boolean;
}

function watch<T>(
  source: () => T,
  callback: (newValue: T, oldValue: T | undefined) => void,
  options?: WatchOptions
): EffectHandle;
```
