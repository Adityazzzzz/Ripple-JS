Ripple is designed to be exceptionally lightweight. 

## Core Size
The core library (`ripple-reactive`) is approximately **~3.5KB minified and gzipped**. 

When compared to pulling in a full framework for reactivity, Ripple provides a massive advantage for standalone libraries, vanilla web components, or performance-critical logic layers.

## Tree-Shaking

Ripple is distributed as ECMAScript Modules (ESM). This means your bundler (Vite, Webpack, Rollup) can easily statically analyze your code and drop any functions you don't use.

If you only use `signal` and `effect`, your final bundle size contribution from Ripple will be significantly less than 3.5KB.

<Aside type="tip">
To maximize tree-shaking, always import exactly what you need from the core package:
```ts
// ✅ Good
import { signal, computed } from 'ripple-reactive';

// ❌ Avoid if possible (though modern bundlers handle it)
import * as rx from 'ripple-reactive';
```
</Aside>

## Checking your Bundle Size
If you are using Vite, you can use `rollup-plugin-visualizer` to see exactly how much space Ripple takes up in your final build:

```bash
npm install --save-dev rollup-plugin-visualizer
```

```ts
// vite.config.ts
import { visualizer } from "rollup-plugin-visualizer";

export default {
  plugins: [visualizer()],
};
```
