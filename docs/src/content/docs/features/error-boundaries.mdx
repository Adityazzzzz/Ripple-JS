If an error is thrown inside an `effect`, it can crash the reactive graph. `catchError` allows you to wrap effect logic and handle errors gracefully.

## Usage

```ts
import { signal, catchError } from 'ripple-reactive';

const rawData = signal('{"bad json"');

catchError(
  () => {
    // This will throw a JSON parse error
    const data = JSON.parse(rawData.value);
    console.log(data);
  },
  (error) => {
    console.error('Failed to parse data:', error.message);
  }
);
```

This ensures that even if the first function throws, the application doesn't crash, and you have a chance to log the error or update an error state signal.
