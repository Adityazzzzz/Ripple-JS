The `resource` utility simplifies asynchronous data fetching. It automatically tracks loading and error states and can re-fetch when source signals change.

## Usage

`resource` takes a source (often a signal or a function returning a value) and a fetcher function.

```ts
import { signal, resource, effect } from 'ripple-reactive';

const userId = signal(1);

const userResource = resource(userId, async (id) => {
  const response = await fetch(`https://api.example.com/users/${id}`);
  if (!response.ok) throw new Error('Failed to fetch');
  return response.json();
});
```

## Resource States

The returned resource object contains reactive signals for its current state:

```ts
effect(() => {
  if (userResource.loading.value) {
    console.log('Loading user...');
  } else if (userResource.error.value) {
    console.error('Error:', userResource.error.value);
  } else if (userResource.data.value) {
    console.log('User data:', userResource.data.value);
  }
});
```

Whenever `userId.value` changes, `userResource` will automatically run the fetcher again.
