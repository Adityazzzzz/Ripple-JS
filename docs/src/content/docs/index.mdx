## Why Ripple.js?

Most reactivity systems are **locked inside UI frameworks**. Ripple.js gives you the same power — signals, computed values, and effects — as **standalone utilities** you can use anywhere.

## Quick Example

```ts
import { signal, computed, effect } from 'ripple-reactive';

const count = signal(0);
const doubled = computed(() => count.value * 2);

effect(() => {
  console.log(`Count: ${count.value}, Doubled: ${doubled.value}`);
});
// Output: "Count: 0, Doubled: 0"

count.value = 5;
// Output: "Count: 5, Doubled: 10"
```
