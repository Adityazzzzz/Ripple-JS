The `subscribe` utility allows you to listen to a specific signal and run a callback when it updates.

## Usage

```ts
import { signal, subscribe } from 'ripple-reactive';

const name = signal('Alice');

const unsubscribe = subscribe(name, (newName) => {
  console.log('Name is now:', newName);
});

name.value = 'Bob'; // Logs: Name is now: Bob
```

## Compared to `effect`

- **`effect`**: Automatically tracks all signals read synchronously inside its callback.
- **`subscribe`**: Only listens to the specific signal you pass it. It does not track other signals read inside the callback.

Use `subscribe` when you want a simple listener without the magic of automatic tracking, or when integrating with non-reactive code.
